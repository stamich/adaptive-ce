# ACE 0.5.0 demo

```bash
./demo/ace-run-demo0.5.0.sh
```

Takes well under a minute after the release build and runs no benchmarks:

1. four workloads generated by `ace-corpus` (structured JSON, u32 counter, u64 ns timestamps,
   random) → compression ratio, CLI throughput, selected codecs per block, verified roundtrip;
2. the Float lane (new in 0.5.0): f64 constant / step / smooth / noisy / sensor series and a
   sparse-change integer series with the lane on and with `--disable-float` → ratio, format
   version (1.3 or 1.4), TS1 modes per block, and the Planner V5 route of one block (`explain`);
3. random-access read of 64 KiB from the indexed file, compared with the source slice;
4. bounded-memory streaming compression, byte-identical to in-memory compression — also for a
   TS1 file whose header the stream encoder rewrites as Format 1.4;
5. determinism: SHA-256 of 1 thread == all threads == `ACE_SIMD=scalar`, for the 0.4 routes
   and for Gorilla blocks.

Scratch files live in `target/demo-0.5.0/` (or under `$CARGO_TARGET_DIR`) and are removed at
the end. Measurements belong to `./ace-benchmark0.5.0.sh`; the full pipeline is
`./ace-build0.5.0.sh` / `./ace-release0.5.0.sh`.
