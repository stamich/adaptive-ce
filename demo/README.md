# ACE 0.4.6 demo

```bash
./demo/ace-run-demo0.4.6.sh
```

Takes well under a minute after the release build and runs no benchmarks:

1. four workloads generated by `ace-corpus` (structured JSON, u32 counter, u64 ns timestamps,
   random) → compression ratio, CLI throughput, selected codecs per block, verified roundtrip;
2. random-access read of 64 KiB from the indexed file, compared with the source slice;
3. bounded-memory streaming compression, byte-identical to in-memory compression;
4. determinism: SHA-256 of 1 thread == all threads == `ACE_SIMD=scalar`.

Scratch files live in `target/demo-0.4.6/` and are removed at the end. Measurements belong to
`./ace-benchmark0.4.6.sh`; the full pipeline is `./ace-build0.4.6.sh` / `./ace-release0.4.6.sh`.
