# ACE 0.2.1-buildfix1 demo

Run:

```bash
./demo/run-demo-0.2.1-buildfix1.sh
```

The demo contrasts FAST and BALANCED planner explanations, verifies deterministic Format-1.1 compression, performs a 64-KiB indexed range read and runs the planner/random-access benchmark families. The buildfix intentionally demonstrates changed planning policy rather than new wire-format functionality.
