# ACE 0.4 demo

Run:

```bash
./demo/run-demo-0.4.sh
```

The demo generates deterministic u32/u64 numeric data, runs the workspace tests, prints Planner V4
numeric diagnostics, creates and verifies a Format 1.3 file, demonstrates Auto block-size selection,
checks thread-count determinism and runs the numeric/ablation/block-policy benchmark families.
